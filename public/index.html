POSIX Multithreaded Core Architecture

Farloom uses zero external HTTP/networking frameworks. Every layer is implemented directly using modern C++20 and standard POSIX sockets.

Layer 01
TCP Acceptor
Single non-blocking thread accepting raw socket descriptors with SO_REUSEADDR.
Layer 02
Bounded Queue
Fixed capacity of 64 jobs. If full, triggers instantaneous 503 backpressure load shedding.
Layer 03
Worker Pool
Fixed 4 POSIX threads waiting on std::condition_variable with graceful drain shutdown.
Layer 04
Router & Guard
Exact path matching + canonicalized static sandbox preventing directory traversal.
Layer 05
HTTP/1.1 Wire
Streaming parser enforcing RFC 9112 limits and SHUT_WR half-close connection drain.
Zero Overhead Error Handling

Custom monadic Result<T, E> provides Rust-like compile-time safety without C++ exception throwing overhead.

Path Traversal Shield

Every file path is sanitized, percent-decoded, and verified component-by-component against boundary escapes.

Graceful Drain Budget

Socket teardown initiates half-close (SHUT_WR) and drains incoming bytes, eliminating spurious TCP RST packets.

Single-Write Logging

Structured key=value log records formatted with microsecond timestamps and atomic stream locking.
